How this result works

  • PASS: Your selected WordPress and PHP versions meet the plugin’s declared requirements.
  • WARNING: The selected WordPress version is newer than the plugin’s declared “Tested up to” version.
  • FAIL: Your selected WordPress or PHP version is below the plugin’s declared minimum requirement.
  • Important: This checks public WordPress.org metadata only. Always test updates on staging before updating a production website.
Uses public metadata from the WordPress.org Plugins API.
